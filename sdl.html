Challenges & solutions

The problem

I wanted to create a Unity-like component based architecture, in a language I was largely inexperienced with.

How I solved it

I took my time to research many of the corresponding things I was already familiar with in C# such as templates. Since I had created a similar project earlier, I knew how I would go about creating the foundation and the architecture. I created a gameobject-based structure since I wanted the same kind of freedom that I had in Unity. 

class GameObject {
    public:
        GameObject(const GameObject &) = delete;
        const GameObject &operator=(const GameObject &) = delete;

        virtual ~GameObject() = default;
        virtual void Start();
        virtual void Update();
        virtual void Draw(SDL_Renderer *ren);
        const SDL_FRect &GetRect() const { return rect; }

        virtual void OnEvent(const SDL_Event &) {}
        virtual void OnCollision(GameObject &other) {}

        template <typename T, typename = std::enable_if_t<std::is_base_of_v<Component, T>>>
        T *GetComponent()
        {
            for (const auto &c : components)
            {
                if (auto ptr = dynamic_cast(c.get()))
                    return ptr;
            }
            return nullptr;
        }

        template <typename T, typename = std::enable_if_t<std::is_base_of_v<Component, T>>>
        void AddComponent()
        {
            auto comp = std::make_unique();
            comp->SetOwner(this);
            components.push_back(std::move(comp));
        }

        Vector2 &GetPosition() { return position; }
        void SetPosition(const Vector2 &newPos) { position = newPos; }
        void SetTag(std::string newTag) { tag = newTag; }
        void MarkForDestruction() { shouldBeDestroyed = true; }
        bool ShouldBeDestroyed() const { return shouldBeDestroyed; }
        std::string GetTag() const { return tag; }

    protected:
        GameObject() = default;
        SDL_FRect rect = {0, 0, constants::unitSize, constants::unitSize};
        std::vector> components;
        Vector2 position = {0, 0};
        std::string tag = "GameObject";
        bool shouldBeDestroyed = false;

    private:
        friend std::ostream &operator<<(std::ostream &os, GameObject &obj);
};

What I learned

It was the first time I've ever developed using C++. I had previous experience with graphics-frameworks, such as my 2D-Sandbox , but this was entirely different. I had to learn memory-management, smart-pointers, constructors and destructors, simple bit-manipulation and more. It was a great learning exercise.
