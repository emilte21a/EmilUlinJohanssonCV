Overview

A custom 2D game engine developed in C++ using the SDL3 framework as part of a C/C++ programming course. The engine was built around a component-based architecture, inspired by Unity's GameObject and Component system. It features manual memory management using modern C++ techniques, alongside custom collision detection, physics and audio systems.

To demonstrate the engine's capabilities, I developed a simple top-down shooter where enemies spawn with basic AI behaviour and pursue the player. Players can eliminate enemies to earn points. The project was an opportunity to explore lower-level game development and understand the underlying systems that make up a game engine.

Challenges & solutions

The problem

One of the biggest challenges was recreating the flexibility of Unity's component-based architecture in C++. Coming from a background primarily working with C#, I was relatively inexperienced with C++ and had to rethink how I approached object management and memory ownership. I wanted GameObjects to be able to hold different types of components that could be retrieved and managed at runtime, without having to create a separate class for every possible combination of functionality.

How I solved it

I implemented a GameObject-based architecture where each object owns a collection of components through std::unique_ptr. I also used C++ templates and dynamic_cast to allow components to be retrieved by type. This allowed me to create reusable functionality that could be attached to different GameObjects without tightly coupling their implementations. Using smart pointers also helped establish clear ownership of components and ensured that their memory was automatically managed when their owning GameObject was destroyed. This gave me a flexible foundation for building gameplay systems on top of the engine. 

class GameObject {
    public:
        GameObject(const GameObject &) = delete;
        const GameObject &operator=(const GameObject &) = delete;

        virtual ~GameObject() = default;
        virtual void Start();
        virtual void Update();
        virtual void Draw(SDL_Renderer *ren);
        const SDL_FRect &GetRect() const { return rect; }

        virtual void OnEvent(const SDL_Event &) {}
        virtual void OnCollision(GameObject &other) {}

        template <typename T, typename = std::enable_if_t<std::is_base_of_v<Component, T>>>
        T *GetComponent()
        {
            for (const auto &c : components)
            {
                if (auto ptr = dynamic_cast(c.get()))
                    return ptr;
            }
            return nullptr;
        }

        template <typename T, typename = std::enable_if_t<std::is_base_of_v<Component, T>>>
        void AddComponent()
        {
            auto comp = std::make_unique();
            comp->SetOwner(this);
            components.push_back(std::move(comp));
        }

        Vector2 &GetPosition() { return position; }
        void SetPosition(const Vector2 &newPos) { position = newPos; }
        void SetTag(std::string newTag) { tag = newTag; }
        void MarkForDestruction() { shouldBeDestroyed = true; }
        bool ShouldBeDestroyed() const { return shouldBeDestroyed; }
        std::string GetTag() const { return tag; }

    protected:
        GameObject() = default;
        SDL_FRect rect = {0, 0, constants::unitSize, constants::unitSize};
        std::vector> components;
        Vector2 position = {0, 0};
        std::string tag = "GameObject";
        bool shouldBeDestroyed = false;

    private:
        friend std::ostream &operator<<(std::ostream &os, GameObject &obj);
};
